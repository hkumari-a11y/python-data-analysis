# Python Coursework: Debugging and Analytical Problem-Solving

**Program:** M.S. Business Analytics, Santa Clara University

## Coursework experience
Graduate programming exercises included reading existing code, identifying where edits were required, fixing function logic, running notebook cells, and checking automated tests.

One exercise involved reasoning about **suffix links and traversal in a trie-like data structure**. That is an algorithms exercise rather than a business analytics project; it is included here as evidence of programming practice, not as a deployed analytics product.

## Problem-solving workflow
1. Read the function contract and assertions.
2. Identify the relevant notebook cell and avoid changing unrelated starter code.
3. Trace input and output behavior.
4. Run available tests and review failures.
5. Recheck edge cases before submission.

## Connection to analytics
These habits also support data work: verifying assumptions, checking transformations, reproducing errors, and validating outputs.

This page summarizes coursework experience. It does not assert that any particular test suite, project, or algorithm was independently implemented from scratch. The repository's actual code files remain the evidence of implementation.
